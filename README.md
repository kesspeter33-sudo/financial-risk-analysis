# 📊 Financial Performance Analysis Dashboard | Power BI

## 📌 Project Overview

The **Financial Performance Analysis Dashboard** is an interactive business intelligence project developed using Microsoft Power BI to analyze financial performance, profitability, operating income, profit growth, and loss-making companies.

The dashboard transforms financial data into meaningful visual insights, allowing users to monitor key performance indicators (KPIs), explore financial trends over time, compare monthly operating income, and investigate transaction-level performance.

The primary objective of this project is to demonstrate how data analytics and visualization can support financial monitoring, business performance evaluation, and data-driven decision-making.

## 📊 Dashboard Overview

The dashboard provides a consolidated view of financial performance through KPI cards, trend charts, comparative visualizations, and detailed transaction records.

### 1. Financial KPI Overview

The dashboard displays the following headline metrics:

| KPI | Displayed Value |
|---|---:|
| Total Profit | 71.57T |
| Average Net Profit | 274.49M |
| Average Operating Income | 5.44bn |
| Average Profit Growth Rate | 241.46M |
| Percentage of Loss-Making Companies | 56.48% |

These KPIs provide a high-level overview of financial performance and profitability.

**Important:** The metric units and calculations should be verified against the underlying data before interpreting or publishing these values.

### 2. Yearly Financial Trend Analysis

The yearly trend visualization displays financial performance from **2008 to 2022**.

This analysis helps users:

- Monitor financial performance over time.
- Identify periods of growth or decline.
- Observe changes in financial trends.
- Identify unusual fluctuations that may require investigation.

The dashboard displays a noticeable increase in the yearly trend around the later years of the period, followed by a decline in the final year shown.

### 3. Sales vs. Profit Analysis

The dashboard includes a comparison between sales-related expenses and net profit.

This visualization helps users:

- Compare financial components.
- Understand the relationship between sales-related values and profitability.
- Identify potential differences between revenue-related performance and profit outcomes.

The displayed chart indicates that the two components contribute approximately 55.96% and 44.04% of the total represented value, respectively.

### 4. Profit Growth Analysis

The dashboard includes a visual analysis of profit growth categories.

The growth categories shown are:

- Low
- Medium
- High

This visualization helps users:

- Compare financial growth categories.
- Identify differences in growth performance.
- Explore financial performance across selected categories.

### 5. Monthly Operating Income Analysis

The dashboard provides a monthly comparison of average operating income.

The chart displays the following values:

| Month | Displayed Operating Income |
|---|---:|
| January | 2.2bn |
| February | 2.3bn |
| March | 13.7bn |
| April | 3.9bn |
| May | 3.5bn |
| June | 3.0bn |
| July | 2.1bn |
| August | 4.6bn |
| September | 3.3bn |
| October | 6.8bn |
| November | 2.2bn |
| December | 3.1bn |

**Key observation:** March shows the highest displayed monthly operating income at 13.7bn, followed by October at 6.8bn.

This analysis can help identify periods with unusually high or low operating income.

### 6. Transaction-Level Financial Analysis

The dashboard includes a transaction table with financial details such as:

- Ticker
- Net profit growth
- Growth category
- Average net profit
- Sum of net profit

The transaction table provides detailed visibility into financial performance and allows users to investigate individual records beyond the summarized KPI cards.

### 7. Interactive Dashboard Filters

The dashboard includes interactive filters for:

- Date
- Manager Expenses

These filters allow users to explore financial performance across different time periods and manager expense selections.

## 🔍 Key Insights

Based on the displayed dashboard:

### 1. Significant Loss-Making Company Percentage

The dashboard reports that **56.48% of companies are loss-making**.

This highlights the importance of investigating profitability and identifying the financial factors associated with losses.

### 2. Monthly Operating Income Variation

March has the highest displayed monthly operating income at **13.7bn**, while several other months display values between approximately 2.1bn and 4.6bn.

This variation may warrant further investigation into seasonality, business activity, or unusual financial events.

### 3. Yearly Financial Fluctuation

The yearly trend shows financial movement across 2008–2022, including a sharp increase followed by a decline near the end of the displayed period.

This suggests the value of monitoring financial trends over time rather than relying solely on aggregate KPIs.

### 4. Financial Performance Requires Multiple Perspectives

The dashboard combines total profit, average net profit, operating income, growth categories, and transaction details.

This demonstrates why financial performance should be assessed using multiple indicators rather than a single metric.

*These are observations from the dashboard display, not confirmed explanations of the underlying business causes.*

## 💡 Business Recommendations

Based on the dashboard's displayed metrics, the following actions could support financial analysis:

### 1. Investigate Loss-Making Companies
Analyze the financial characteristics of loss-making companies to identify possible drivers of negative profitability.

### 2. Monitor Monthly Operating Income
Investigate unusually high or low monthly operating income values and determine whether they reflect recurring patterns or one-time events.

### 3. Strengthen Profitability Monitoring
Track net profit and operating income alongside total profit to gain a more complete view of financial performance.

### 4. Analyze Yearly Financial Trends
Review yearly performance changes to identify periods requiring further financial investigation.

### 5. Review Growth Categories
Compare companies or records across Low, Medium, and High growth categories to understand differences in financial performance.

### 6. Improve Transaction-Level Analysis
Use detailed transaction records to investigate unusual financial results and identify potential areas for further analysis.

*These recommendations are proposed analytical actions. They should be validated with the underlying data and business context.*
